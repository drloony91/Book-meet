# Feature map

Каждая строка фиксирует сквозной contract: **frontend → API → data/entities → permissions → tests**. Детали таблиц и FK — [DATA_MODEL.md](./DATA_MODEL.md); endpoint-матрица — [ROUTES_AND_API.md](./ROUTES_AND_API.md).

| Feature | Frontend → API | Data/entities → permissions | Tests / contracts |
| --- | --- | --- | --- |
| Auth/account | `app/screens/AuthScreens.tsx`, controller `login/register/logout/resolveDeletedProfile` → `/api/auth/*`, `/api/users/me/profile`, `/api/linked-profiles/*`, `/api/auth/totp/*` | `users`, `sessions`, `account_action_tokens`, `linked_profiles`; `server/security.js`, legal gate, session owner/admin rules | `tests/security.test.mjs`, `tests/compliance.test.mjs`, `tests/production-contract.test.mjs` |
| Profiles, linked profiles, privacy | `ProfileScreens.tsx`, `UsersDirectoryScreen.tsx`, controller `handleUserChange` → `/api/users/me/state`, `/api/users/me/home-view`, `/api/linked-profiles/*` | `profiles` 1:1 `users`, `linked_profiles`; `profileAccessState`, age/birth-date and viewer-aware follower/friend/wishlist visibility. Owner/admin always see, `friends` requires confirmed friendship, never membership; unavailable list data/counts are omitted by `loadUsers`. | `tests/architecture-security.test.mjs`, `tests/desktop-identity.test.mjs`, `tests/mobile-profile-contract.test.mjs` |
| Feed/materials/reactions/saves/comments | `ContentScreens.tsx`, `ContentComponents.tsx`, `useBookMeetController.toggleLike/toggleSave/addComment` → `/api/reactions`, `/api/saves`, `/api/comments`, `/api/material-stats`, `/api/materials/:kind/:id` | reviews/excerpts/publisher_news/events/occasions + polymorphic `material_likes`, `material_saves`, `material_comments`, `material_books`; readable material, block, age, ownership/admin | `tests/security.test.mjs`, `tests/architecture-security.test.mjs`, `tests/mobile-content-routes-contract.test.mjs`, `tests/spreadsheet-lazy-contract.test.mjs` |
| Books/catalog/library/wishlist/import | `ContentComponents.tsx`, `components/books/ReadingStateFields.tsx`, `services/library-mutations.ts`, `ProfileScreens.tsx`, `ContentScreens.tsx`, `services/spreadsheet.ts` → `/api/books`, `/api/books/catalog`, `/api/books/preview`, `/api/community-books`, `/api/wishlist/*`, `/api/admin/books/import/*` | `books`, `book_links`, `user_books`, `reading_cycles`, `wishlist_items`; personal state is one of want/reading/read/abandoned/postponed. Community associations only reference existing catalogue books; owner, friend reservation, adult material, admin import; external preview validated server-side | `tests/book-query.test.mjs`, `tests/reading-client.test.mjs`, `tests/reading-demo-http.test.mjs`, `tests/profile-completion-community-contract.test.mjs`, `tests/material-search.test.mjs`, `tests/security.test.mjs`, `tests/spreadsheet-lazy-contract.test.mjs` |
| Events | `ContentScreens.tsx`, controller `createEvent/edit/moderateEvent` → `/api/events`, `/api/events/:id/attendees`, `/api/events/:id/reminder`, `/api/admin/events/:id` | `events`, `event_reminders`, `material_books`, optional `books/cities`; creator edits/deletes own pending material, admin moderates, age/city validation | `tests/bootstrap-router.test.mjs`, `tests/compliance.test.mjs`, `tests/production-contract.test.mjs` |
| Occasions | `ContentScreens.tsx`, controller `createOccasion/edit/moderateOccasion` → `/api/occasions`, `/api/admin/occasions/:id` | `occasions`, optional `cities/books/material_books`; creator ownership, admin moderation, age and target profile/city validation | `tests/compliance.test.mjs`, `tests/mobile-content-routes-contract.test.mjs` |
| Social: friendships/follows/communities | `ProfileScreens.tsx`, `UsersDirectoryScreen.tsx`, controller `send/accept/reject/removeFriend`, `followUser` → `/api/social/friend-requests/*`, `/api/social/friends/*`, `/api/social/follows/*` | `friend_requests`, symmetric `friendships`, `follows`, `community_memberships`; `canCreateFriendRequest`, `canMessagePair`, blocks and cross-age cleanup; membership ≠ friendship | `tests/architecture-security.test.mjs`, `tests/compliance.test.mjs`, `tests/desktop-identity.test.mjs` |

| Admin/moderation/compliance | `components/admin/*`, `components/safety/*`, `components/compliance/AccessGate.tsx`, `AdminStatisticsPanel.tsx` → `/api/admin/*`, `/api/reports*`, `/api/legal/acceptances`, `/api/users/me/telegram-notifications` | `reports`, report history/appeals, `moderation_audit_log`, legal documents/acceptances, security logs/incidents, suspensions; server `isAdmin`, report ownership and legal state | `tests/security.test.mjs`, `tests/compliance.test.mjs`, `tests/architecture-security.test.mjs`, `tests/production-contract.test.mjs` |
| Localization | `app/i18n/index.tsx`, `messages.ts`, `LocaleSwitcher.tsx` → `Accept-Language`/`X-BookMeet-Locale` headers on `apiFetch`; server `modules/i18n.js` | `users.preferred_locale`, locale-aware legal documents and auth errors; supported `ru`, `kk`, `en` | `tests/i18n.test.mjs`, `tests/production-contract.test.mjs` |
